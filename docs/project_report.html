1. Abstract & Objective

Manual simplification techniques, such as Karnaugh Mapping, become error-prone and visually intractable beyond four input variables. This project implements LogicBench, an exact algorithmic synthesis suite combining the Quine-McCluskey (Tabular) Method and Petrick's Method. The platform computes exact minimum literal covers, extracts Essential Prime Implicants (EPIs), visualizes Gray-code grouping on interactive K-maps, renders gate schematics, and generates synthesized IEEE-1364 Verilog HDL.

2. Two-Phase Algorithmic Pipeline

Phase 1: Prime Implicant Generation (Quine-McCluskey)

  1. Hamming Partitioning: Given canonical minterms (Σm) and Don't Cares (Σd), inputs are expressed as n-bit binary vectors grouped strictly by their Hamming weight (number of 1s).
  2. Consensus Elimination: Terms in adjacent groups k and k+1 differing by a single bit position (Hamming distance = 1) are merged. The differing bit is replaced with a wildcard hyphen (-).
  3. Prime Extraction: The process repeats iteratively until no further terms can be combined. All uncombined terms form the set of Prime Implicants (PIs).

Phase 2: Coverage Matrix & Essential Extraction

  1. A coverage table is constructed mapping extracted Prime Implicants against required minterms (Σm, excluding Don't-Cares).
  2. Any minterm covered by exactly one Prime Implicant identifies that term as an Essential Prime Implicant (☆ EPI) and is unconditionally included in the minimal cover.
  3. Any remaining cyclic minterms are covered using Petrick's minimal literal heuristic to find the exact global minimum.

  output wire F
